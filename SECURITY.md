# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting: [open a private report](https://github.com/rlopc/agora/security/advisories/new), or open the repository's Security tab and choose "Report a vulnerability". Do not report them in public issues, pull requests or discussions.

Include what is affected (commit), how to reproduce it and its impact, if you know it.

## What to expect

Agora is maintained by one person, on a best-effort basis:

- The report is acknowledged within 14 days.
- A confirmed vulnerability is fixed on `main` and disclosed through a GitHub security advisory once the fix is out. The reporter is credited, unless they prefer not to be.

## Supported versions

Agora has no releases yet: only the latest commit on `main` gets security fixes.

## Scope

What Agora protects and what it leaves to each agent tool is in [docs/specification.md](docs/specification.md#permissions-security-and-known-limits).
